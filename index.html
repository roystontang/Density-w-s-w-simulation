Outcomes: measure mass (balance) and volume (ruler and water displacement); calculate density = mass ÷ volume; use density to predict sink or float in water (1 g/cm³). Please check against the current MOE Lower Secondary Science syllabus. Time: 60 minutes.

Per pair: electronic balance, 30 cm ruler, 100 mL measuring cylinder with 50 mL water, dropper, paper towel, tray, calculator. Objects: A wooden block, B aluminium or plastic block, C metal nut or small stone. Use the same tray layout every time. Use safe, unscented materials.

Supports for students with ASD: show the plan first and warn about changes early; give one literal instruction per step; use checklists and diagrams; allow headphones, a quiet bench, a solo option and written role cards; allow extra time; accept answers by writing, ticking, drawing or speaking; agree a break signal before the lesson.

Misconceptions: “heavy things sink” and “big things sink”. Density compares mass for each cm³. 1 mL = 1 cm³.

Worked example (show first): Object X is 120 g, 4 cm × 5 cm × 3 cm. Volume = 60 cm³. Density = 120 ÷ 60 = 2 g/cm³. 2 is more than 1, so it sinks.

Typical densities (g/cm³): wood 0.4 to 0.9 · plastic 0.9 to 1.4 · aluminium 2.7 · iron 7.8 · water 1.0. Test every object once before the lesson.

The question

Which objects will sink in water, and which will float?

  • Mass: how much matter is in an object. Unit: grams (g).
  • Volume: how much space an object takes up. Unit: cm³ or mL.
  • Density: mass in each 1 cm³. Density = mass ÷ volume. Unit: g/cm³.
  • Water density = 1 g/cm³. More than 1: sinks. Less than 1: floats.

Roles: Measurer (uses balance, ruler, cylinder). Recorder (writes numbers, uses calculator). Swap after Object B. Working alone? Do both jobs.

The rule
  • Object density more than liquid density: the object sinks.
  • Object density less than liquid density: the object floats.
  • Object density equal to liquid density: the object stays suspended in the liquid.

Density values are typical and approximate. Real objects can differ a little.
